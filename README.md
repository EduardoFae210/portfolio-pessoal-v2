# Portfólio Pessoal V2

Portfólio profissional de Eduardo Faé Zanchet, estudante de Ciência da Computação na Universidade de Passo Fundo.

## Funcionalidades

- layout responsivo;
- navegação móvel;
- modo claro e escuro;
- preferência de tema salva com localStorage;
- seções de apresentação, habilidades, projetos, formação e contato;
- cuidados básicos de acessibilidade;
- pronto para publicação no GitHub Pages.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Executar localmente

```bash
python3 -m http.server 8000
```

Abra `http://localhost:8000`.

## Publicação

No GitHub, acesse **Settings > Pages**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`.
